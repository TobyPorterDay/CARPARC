# Part Type Vocabulary

Closed vocabulary for the `part_type` field. 12 values. One value per listing.

## Rules

- Exhaustive: every listing in Labels.csv gets exactly one of these values.
- Mutually exclusive: if two values could both apply, the definitions are wrong — fix the definitions, not the label.
- A listing naming multiple parts gets the label for the dominant part. Record it in Ambiguities below.
- Decide now whether one slot is a catch-all (`OTHER`). If yes, it counts against the 12.
